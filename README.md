# Elangbamjohnson Tap

## How do I install these formulae?

`brew install elangbamjohnson/tap/<formula>`

Or `brew tap elangbamjohnson/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "elangbamjohnson/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
